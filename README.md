# AI 模型数据标注知识库公开站点

公开网址：<https://vegaac.github.io/ai-data-labeling-knowledge-base-site/>

本仓库只发布去公司画像化的通用知识内容，面向需要了解 AI 模型训练数据标注的学校、实验室和研发团队。

## 内容边界

允许公开：

- 通用行业与技术知识；
- 数据标注、质量、交付与系统方法；
- 不对应真实项目的解释性示例。

禁止公开：

- 团队规模、预算、内部周期和收入目标；
- 城市资源、学校/医院关系和真实合作进展；
- 客户、学校、教师、科室和联系人信息；
- 真实数据、合同、账号、凭据和未公开科研资料。

公开站点使用干净仓库历史，与内部定制知识库完全分离。
