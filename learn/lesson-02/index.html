Lesson 02

数据模态与标注任务类型

目标：看到一个模型数据需求时，能从“输入是什么、人工做什么、输出长什么样、数据用于哪里”四个方面准确拆解。

本课目录
四层拆解法四种工作文本图像音频与视频点云大模型同数据不同任务询问清单练习
本课先记住四句话

模态是输入；任务是人工动作；格式是结果结构；用途是数据进入训练、验证、测试或评测的哪个环节。

1. “模态—任务—格式—用途”四层拆解法

层次要问什么例子
数据模态输入是什么？中文客服对话
标注任务人工做什么？判断意图并标出实体
交付格式结果长什么样？意图、实体文本和起止位置组成的 JSON
模型用途数据用在哪里？意图识别模型训练集
专业任务描述

对中文客服对话进行意图分类和实体抽取，按照规范输出 JSON；数据用于模型监督微调，委托方提供意图体系并仲裁业务难例。

信息不足的说法

“有一批文本要标注。”这句话无法确定工具、人员、工时、质量方法和报价。

2. 采集、清洗、标注和评测不是一回事

工作通俗解释例子
数据采集获得原始材料拍照、录音、收集公开文档
数据清洗去掉或修复不能使用的数据去重、修复格式、过滤损坏文件
数据标注为样本增加结构化答案分类、框选、转写、关系抽取
模型评测检查已有模型表现评价答案正确性、安全性和证据
为什么要区分

四类工作的工具、专业人员、成本和验收标准不同。学校说“有一批数据要处理”时，要继续问具体是哪一种。

3. 文本数据

  • 文本分类：给整段文字选择情感、主题、风险或用户意图。
  • 实体抽取：标出人名、机构、时间、术语等文本片段。
  • 关系抽取：判断两个实体之间的关系。
  • 问答构建：根据文档制作问题、参考答案和证据出处。
  • 内容审核：判断有害、隐私、虚假或不适合的内容。
术语注释 · 实体抽取

除了实体类别，还经常需要记录文字在原文中的起止位置。输入版本或字符编码变化，位置就可能错位。

4. 图像数据

任务回答的问题典型输出
图像分类整张图是什么？一个或多个类别
目标检测物体大概在哪里？矩形框坐标 + 类别
语义分割每个像素属于什么？类别掩膜
实例分割同类不同物体分别在哪里？实例掩膜 + ID
关键点特定结构点在哪里？点坐标和可见性
OCR图中有哪些文字？文字区域 + 转写内容
为什么不能只按图片数量报价

一张图里有几个物体、遮挡是否严重、边界多精细，都会显著改变工时。逐像素分割通常比整图分类耗时得多。

5. 音频与视频数据

音频常见任务

  • 语音转写；
  • 语句或词语时间戳；
  • 说话人分离；
  • 情绪、发音或口音；
  • 音频事件检测。
计量注释

音频工作量通常看总时长，而不是只看文件数。还要了解有效语音比例、噪声、口音、说话人数和时间戳精度。

视频常见任务

  • 逐帧目标检测；
  • 同一物体的跨帧跟踪；
  • 动作识别；
  • 事件起止时间；
  • 视频分割、描述或问答。
为什么视频不等于很多张图片

视频包含时间连续性。报价要考虑帧率、关键帧、跟踪 ID、遮挡、插值工具和自动跟踪后的人工修正。

6. 点云与三维数据

点云由大量三维坐标点组成，常用于激光雷达、机器人、测绘和自动驾驶。

  • 三维框；
  • 点级分割；
  • 三维目标跟踪；
  • 车道线或空间结构；
  • 相机与点云对齐；
  • 方向、遮挡和运动属性。
项目风险

点云任务需要专业工具、图形性能、坐标系知识和复杂规范。没看样本和工具前，不应承诺固定单价或产能。

7. 大模型与多模态数据

大模型项目中的标注不一定是“选标签”，也可能是写答案、比较回答或按规则评分。

  • 指令—回答示例编写；
  • 事实性、相关性、完整性和安全性评分；
  • 多个回答的偏好排序；
  • 事实核验和证据绑定；
  • 安全评测与红队测试；
  • RAG 检索和回答质量评测；
  • 图文、音视频等多模态问答。
术语注释 · Rubric

Rubric 是评分规则表，把“回答好不好”拆成可判断维度，并说明每个分数代表什么。

术语注释 · RAG

检索增强生成：系统先从文档中找资料，再让模型基于资料回答。评测时要分别判断检索是否相关、回答是否忠于证据、是否完整。

8. 同一份数据可以对应不同任务

以一张农作物叶片照片为例：

模型目标标注任务输出
判断是否患病图像分类健康/患病
找到病斑位置目标检测矩形框 + 病斑类别
计算病斑面积图像分割像素掩膜
回答病害问题图文问答问题 + 参考答案
检查模型解释多维评分正确性、依据和完整性评分

9. 报价和选系统前至少问十个问题

  1. 输入模态、格式、数量和总大小是什么？
  2. 人工具体执行什么动作？
  3. 每个样本平均有多少对象、片段或判断项？
  4. 输出字段、坐标、时间戳或评分格式是什么？
  5. 数据用于训练、验证、测试还是评测？
  6. 谁定义标签并仲裁专业难例？
  7. 质量如何抽样、计算和验收？
  8. 数据能否离开学校，部署和权限有什么要求？
  9. 是否允许预标注和其他自动化？
  10. 能否先用代表性样本试标？

10. 今日练习

请对下面四个需求，分别写出模态、任务、格式、用途：

  1. 从学校公开规章中制作“问题—答案—证据出处”；
  2. 标出显微图像中的细胞位置和轮廓；
  3. 把课堂录音转成带说话人和时间戳的文字；
  4. 评价大模型回答是否事实正确并有文档依据。
作答格式

模态：文本；任务：问答构建和证据绑定；格式：JSON；用途：RAG 模型训练或评测。
