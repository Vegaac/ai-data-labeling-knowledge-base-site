Lesson 01

数据标注产业链与服务商定位

目标：能清楚说明谁提出模型需求、谁设计数据生产、谁执行标注，以及专业数据服务商真正对什么负责。

本课目录
三句话卖什么三层结构项目例子服务商定位练习
本课先记住三句话

甲方购买的是可用于模型的数据集；平台层把需求转成稳定生产流程；执行人员数量不是核心竞争力。

1. 四个基础术语

标签体系
允许标注人员选择或填写的分类、属性和关系集合。
标注规范
说明每个标签什么时候用、什么时候不用，以及边界和疑难如何处理。
金标
由可信专家确认、用于培训或检查质量的标准答案。
验收
委托方按照约定检查文件、标签、质量证据和可用性，并决定是否接收。

2. 数据标注公司真正卖什么

模型或业务问题
→ 可执行标签规则
→ 受控系统与合格人员
→ 可测量的质量
→ 有版本的数据集
→ 训练、验证、测试或评测使用

如果只提供人员，委托方仍要自己写规则、搭系统、培训、质检、处理返工和管理版本。专业服务商的价值，是把这些环节组合成稳定交付。

3. 需求、平台、执行三层

层次负责什么
需求层模型目标、数据用途、领域标准、预算和验收
平台层样本审计、标签、规范、系统、人员、质检、版本和交付
执行层按照规范完成标注、复核或领域判断
为什么只组织人员不够

人员数量容易被替代和比价；规则工程、质量体系、数据安全、版本管理和项目交付更难复制，也更接近委托方真正的风险。

4. 学校模型项目例子

某课题组要评测大模型的专业问答：

  • 学校说明模型用途、不可接受的错误和专业判断标准；
  • 数据服务商把“回答好不好”拆成事实性、相关性、完整性、安全性和证据等维度；
  • 领域教师制作少量标准样本并仲裁专业难例；
  • 标注与质检人员按统一规范完成评分；
  • 企业交付评测数据、规范版本、质量报告和已知问题。
关键观察

教师不需要逐条完成全部标注，但必须确认专业标准；企业不能替教师擅自决定专业答案，却要负责把标准转成可执行流程。

5. 专业服务商的可信定位

更可信的表述是：

定位示例

我们把模型项目的数据需求转化为标签规范、受控系统、人员培训、质量闭环和版本化交付，并对约定的数据质量和项目管理负责。

不应轻易宣称“任何数据都能做”“准确率绝对有保证”或“数据一定让模型达到某个效果”。

6. 练习

  1. 需求层、平台层和执行层分别负责什么？
  2. 为什么人员数量不能成为唯一竞争力？
  3. 学校训练模型时，学校、企业和领域教师分别承担什么？
  4. 用 120—200 字写一段数据标注服务商定位。
